# T-Invest Smart Assistant (Sidepanel Extension)

Прототип расширения для браузера (в формате Sidepanel), разработанный в рамках хакатона Т-Банка «Инвест.Премаркет». Интегрирует ненавязчивый opt-in виджет, который снижает отток (churn rate) розничных трейдеров и защищает новичков от импульсивных ошибок с помощью контекстных статьей и квизов.

## Архитектура и функционал

- Контекстный триггер: Интеграция с API / Песочницей Т-Банка через MCP-сервер для анализа паттернов сделок в реальном времени.
- Интерактивные чекпоинты: Динамический вызов обучающих модулей и тестов в боковой панели на основе оценки рисков ИИ-агентом.
- Стабильный интерфейс: Изолированная логика компонентов на React с кастомной валидацией состояний (кнопки, экраны) без избыточной нагрузки на хранилище.

## Стек технологий

- Фреймворк: WXT (Vite)
- Фронтенд: React, TypeScript
- Стилизация: Tailwind CSS, кастомизированный shadcn/ui
- Интеграции: T-Invest API, MCP Server Architecture

## Запуск проекта

1. Клонировать репозиторий:
  
   git clone https://github.com
   cd T-SafetyNet
   
2. Установить зависимости:
  
   npm install
   
3. Запустить сервер разработки:
  
   npm run dev
